# Urban Scooter – Manual Testing Project

## Project Overview

This project contains manual testing performed on the **Urban Scooter** application.  
The objective of the testing process was to validate the functionality, data validation, and overall behavior of both the **web application** and the **mobile application**.

The testing activities included functional testing, form validation testing, mobile UI testing, network testing, and API testing.

---

## Testing Scope

The project covers testing of two platforms:

- Web application testing
- Mobile application testing

Both platforms were tested to ensure correct functionality, proper handling of user input, and stable behavior under different conditions.

---

## Web Application Testing

Testing of the web version of Urban Scooter focused on validating key functionality and form data validation.

### Activities performed

- Functional testing using checklists
- Validation of user input fields
- Identification of defects

### Artifacts

The following documentation is included:

- Functional checklist
- Form validation test design

These files are located in the **web-testing** folder.

---

## Mobile Application Testing

Testing was also performed on the Urban Scooter mobile application.

### UI Testing
Verification of the mobile interface layout and usability.

Examples:
- Layout consistency
- Button visibility
- Navigation between screens

### Network Testing
Validation of application behavior when connectivity is lost.

Examples:
- Loss of internet connection
- Offline behavior
- Error messages displayed to users

### API Testing
Validation of communication between the mobile app and backend services.

Examples:
- API responses
- HTTP status codes
- Data returned by endpoints

Mobile testing artifacts are located in the **mobile-testing** folder.
