# Urban Scooter – Mobile Testing

## Overwiew

This section of the project contains manual testing performed on the **Urban Scooter mobile application**.

The objective of these tests was to validate the behavior of the mobile app under different conditions, including user interface consistency, network interruptions, and backend communication through APIs.

The testing activities were divided into three main areas: UI testing, network testing, and API testing.

---

## UI Testing

User interface testing focused on validating the visual layout and usability of the mobile application.

The following aspects were verified:

- Correct alignment of interface elements
- Visibility and accessibility of buttons
- Proper navigation between screens
- Layout consistency across screens
- Correct display of text and icons

Artifacts related to UI testing can be found in the **ui-testing** folder.

---

## Network Testing

Network testing focused on verifying how the application behaves when the user experiences connectivity issues.

The following scenarios were tested:

- Loss of internet connection
- Behavior of the app while offline
- Error messages displayed to the user
- Application behavior after connection is restored

Artifacts related to network testing can be found in the **network-testing** folder.

---

## API Testing

API testing was performed to validate the communication between the mobile application and the backend services.

The following aspects were verified:

- Correct API responses
- HTTP status codes
- Data returned from endpoints
- Consistency between API responses and the app behavior

Artifacts related to API testing can be found in the **api-testing** folder.
