# Urban Scooter – Manual Testing Project

## Project Overview

This project focuses on manual testing of the **Urban Scooter** web application.  
The objective of the testing process was to verify core functionality and validate user input fields to ensure the application handles both valid and invalid data correctly.

The testing activities included creating functional checklists and designing test scenarios for form data validation.

---

## Testing Scope

The following testing activities were performed:

- Functional testing using checklists
- Input validation testing for form fields
- Identification and documentation of defects

The goal was to confirm that the application behaves correctly under different user input conditions.
